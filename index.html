Projects

Each one started as a real annoyance: files piling up, grades scattered across spreadsheets, stock nobody tracked until it ran out. I built a small tool to fix each, then documented it properly and put it on GitHub.

01

File Organizer

Downloads folders pile up fast, and sorting them by hand is tedious. This command-line tool solves that by scanning a folder and sorting every file into subfolders by type. It shows a preview before moving anything, and it renames duplicates instead of overwriting files.

Challenge: two files with the same name shouldn't overwrite each other. I solved it by checking if the destination already exists and appending (1), (2), and so on until the name is free.

  • Python
  • pathlib
  • argparse
  • shutil

02

Grade Tracker

Tracking grades by hand in a spreadsheet gets messy once there are several subjects per student. This Java console app keeps it organized: it calculates averages and shows per-student reports, checks every input, and saves data to a file so it is still there the next time you run it.

Challenge: the saved file could get edited by hand and end up with a broken line. I made the loader skip any line that doesn't parse cleanly instead of crashing the whole program on startup.

  • Java
  • File I/O
  • Collections

View the code on GitHub

03

Inventory Manager

Small stockrooms often lose track of what's running low until it's too late. This C# console app fixes that by totaling the value of your inventory and flagging items that are running low, on top of checking every input and saving data to a file so it is still there the next time you run it.

Challenge: stock can't go negative, but a person might type letters, a decimal, or a number bigger than what's in stock. I used TryParse with a retry loop so a bad entry just asks again instead of crashing.

  • C#
  • .NET
  • LINQ
  • File I/O
